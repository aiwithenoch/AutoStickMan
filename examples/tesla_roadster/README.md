# Tesla Roadster example

This is the first complete AutoStickMan run. It uses the exact cream-paper stickman reference, 13 standalone generated frames, `en-US-BrianNeural`, and the fact-checked Tesla Roadster science workflow.

The rendered video is a keyframe flipbook animatic rather than full hand-drawn frame-by-frame animation. The source workflow documents which statements are established physics, Tesla-published claims, or not independently verified. Captions use the actual Edge TTS word boundaries, so they follow Brian's speech and pauses rather than evenly dividing each scene.
